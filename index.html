Same Brain?

A question game for two friends on one phone. Answer in secret, then find out if you think alike.

How long?
What kind of questions?

How to play
  1. Same brain: you both answer in secret. Same answer? You both get a point.
  2. Guess me: one of you answers about yourself. The other guesses. Right guess = 1 point.
  3. Talk time: no points. Just talk about the question. Use the timer if you want.
  4. Dare: do a simple dare. Did it? +1 point. Too shy? Skip it.
  5. Pass the phone when the game tells you. No peeking!
